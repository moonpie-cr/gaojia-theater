## 🚪 怎么进场？

| 设备 | 方法 |
|---|---|
| 💻 电脑 | 双击 `gaojia_theater.html`，用 Chrome / Edge / Safari 打开 |
| 📱 手机 | 把文件发到手机，用浏览器或微信打开，横屏竖屏都 OK 🙆 |

## 🍱 小戏《送饭记》（约 70 秒）

敲一下台下的大锣 🔔 就开演！这是一出原创小喜剧：

1. 🌸 **后花园**：小姐甩着水袖说心事，丫鬟春桃提着食盒来送饭
2. 🤡 老院公学傀儡一顿一挫地上台，想偷吃，被春桃抓个正着 🙈
3. 💙 媒婆甩着头发冲出来：「看我拉你见官去！」
4. ⚖️ **换景到公堂**：大人坐上公座，啪地一拍惊堂木。院公跪下：「小人只是……馋了！」😂
5. 🎉 大人罚院公再跳一回傀儡，大家哈哈大笑，最后全体亮相谢幕 👏

🔦 演出时追光会跟着说话的人跑，字幕同步显示台词～

## 📖 高甲戏小知识

点横幅、演员、锣鼓、桌子、观众席，右边竖屏就会竖着显示一条小知识，一共 10 条：

| 点哪里 | 讲什么 |
|---|---|
| 🎏 横幅 | 高甲戏是什么 |
| 🤡 丑角 | 傀儡丑 |
| 🌸 花旦 | 高甲戏的行当 |
| 💃 闺门旦 | 水袖 |
| 💙 彩旦 | 甩发 |
| 🔴 武将 | 宋江戏 |
| 🔔 大锣 | 武乐 |
| 🥁 堂鼓 | 文乐 |
| 🪑 桌子 | 一桌二椅 |
| 👏 观众席 | 高甲戏流行在哪些地方 |

🍵 先尝一口：
- 🏯 高甲戏是闽南的地方戏，又叫「九角戏」「大班」，孕育于明末清初
- 📚 早期主要演宋江的故事，所以也叫「宋江戏」
- 🤡 各个行当里，丑角最出彩！傀儡丑就是模仿提线木偶的动作
- 🏅 2006 年列入第一批国家级非物质文化遗产名录

> 📝 内容参考中国非物质文化遗产网的「高甲戏」词条

## 🙋 遇到问题？

**🔇 没有声音？**
先在画面上点一下；再看看手机是不是静音了（iPhone 侧面的静音键打开时，网页也不会出声哦）

**🐢 手机有点卡？**
网页会自己判断手机性能，卡的时候会自动关掉阴影、降低清晰度，稍等一下就顺啦 🚀

**🎺 想换成真实的锣鼓声？**
在网页旁边新建一个 `audio` 文件夹，放进这些文件：

- 🔔 `gong.mp3` 锣
- 🥁 `drum.mp3` 鼓
- 🪵 `wood.mp3` 木鱼 / 梆子
- 🎺 `suona.mp3` 嗳仔 / 唢呐
- 👏 `applause.mp3` 掌声

⚠️ 这个要把网页放到网站服务器上才生效；直接双击本地文件打开时，浏览器不让读旁边的音频，网页会继续用自带的合成音效～

**📜 指南不见了？**
点台前右边的红色「戏单」牌就能再打开 🪧
